# Python Functions Assignment Solutions

Contains one file for each of the 15 exercises in the supplied assignment, plus the optional bonus.

## Files
- `ex01.py` to `ex05.py`: Part A — Easy
- `ex06.py` to `ex10.py`: Part B — Medium
- `ex11.py` to `ex15.py`: Part C — Logical
- `bonus.py`: Bonus — Marks converter using a closure

## Run
Open this folder in VS Code and run one exercise at a time:

```powershell
py ex01.py
```

Replace `ex01.py` with the file you want to run.

Function names follow the assignment. Return values are used as requested, except Exercise 8 and Exercise 15, which specifically ask for printed output. Exercise 6 uses a non-empty list, matching the assignment test.
